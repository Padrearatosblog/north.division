# North Division Engineering Group — Demo

Demo cinematográfica de ingeniería estructural construida con React, TypeScript y Vite.

## Desarrollo

```bash
pnpm install
pnpm run dev
```

## Verificación

```bash
pnpm run build
pnpm run lint
```

## GitHub Pages

El workflow de `.github/workflows/deploy-pages.yml` compila y publica automáticamente al hacer push a `main` o `master`.
